🧹 PassMerge

Merge login items that belong to the same service across country domains (zalando.ch + zalando.de + fr.zalando.ch → one Zalando item). Your password data never leaves your browser.

If you've ever exported your Bitwarden vault and found amazon.com, amazon.de and amazon.fr sitting there as three separate logins with the exact same email and password — this tool is for you. It detects logins that share the same underlying service across country-code domains and merges the duplicates back into one clean item, right in your browser.

Why do these duplicates happen?

Browsers and password managers usually save one entry per domain you actually visit. Since many international sites use a different domain per country (.ch, .de, .fr, .co.uk…) for what is really the same account, your vault slowly fills up with near-identical duplicates. PassMerge strips the country suffix and subdomain to find the shared brand — fr.zalando.ch and accounts.zalando.com both become zalando — and offers to merge everything that shares a brand and username into one item with every URL attached.

How it works

  • Export your vault as CSV (or use an export from Chrome, Firefox, LastPass, Dashlane, Apple Passwords, NordPass or Proton Pass — the tool auto-detects the format).
  • The tool groups items by brand + username and shows you, one group at a time, exactly what it wants to merge.
  • Any real conflict (a different password, folder, or username) is never resolved silently — you pick, or remove just the one entry you're sure about with its own trash icon.
  • Download a ready-to-import cleaned.json, plus a full text report of every decision made.

Frequently asked questions

Why does Bitwarden have several entries for the same account?

Autofill and browser password-saving prompts often create one Bitwarden item per domain you visit — so the same account on zalando.ch, zalando.de and fr.zalando.ch ends up as three separate items instead of one. PassMerge detects the shared brand behind these domains and merges them back into one item with all the URLs attached.

Is it safe to upload my password export to this tool?

Your CSV file itself is never uploaded anywhere — it's read and processed entirely as JavaScript in your own browser tab, and the output files are generated locally. The site does use privacy-conscious Google Analytics to count visits; that only sees which pages you view, never your file or its contents.

Which password managers' exports does it support?

Bitwarden's own CSV export natively. The tool also auto-detects and reads exports from Chrome, Edge, Brave, Firefox, LastPass, Dashlane, Apple Passwords, NordPass and Proton Pass — the output is always a Bitwarden-ready file.

What happens if the duplicate entries have different passwords?

Nothing is ever discarded silently. If a password differs, you're asked which one to keep — the other variant is also written into the merged item's notes and flagged in the report.

How do I get the merged data back into Bitwarden?

Download cleaned.json and import it: Bitwarden web vault → Settings → Import/export data → Import data → format .json (Bitwarden). Test in an empty vault first if you're not sure.
